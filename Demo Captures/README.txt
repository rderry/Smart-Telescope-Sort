Telescope Data Sort — Demo Captures
====================================

These folders mimic Captures AFTER copying TIFF/FITS off each smart telescope
(USB / FTP / Wi-Fi). Files are tiny placeholders so you can exercise Sort safely.

How to use
----------
1. Open Telescope Data Sort.app
2. Click Choose… beside Capture Folder and pick one of the folders below
   (e.g. …/Demo Captures/Seestar). The folder layout is detected
   automatically and shown under the window title; there is no telescope
   type to set. Choosing the Demo Captures parent also works.
3. Refresh preview, then Review file plan.

Folders
-------
Vaonis/   — Singularity dated observation/plan trees (TIFF/FITS)
Seestar/  — Object albums with FIT/FITS
DWARF/    — Session folders with FITS/TIFF
Origin/   — Object_YYYY-MM-DD raw FITS folders

Other telescopes and cameras
----------------------------
Images from any other telescope or camera, including classic setups, sort
the same way when each object's TIFF/FITS (or JPG) files are in a folder
named for the object, e.g. Captures/M31/*.fits or
Captures/2026-10-07/NGC 7000/*.fit. Frames left inside Light, Dark, Flat,
Bias or Master folders are set aside, not sorted. See "Using data from
other telescopes" in the user manual.
